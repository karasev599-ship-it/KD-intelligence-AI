# KD Messenger Flutter App

Standalone mobile/desktop client scaffold for KD Messenger.

## Targets
- iOS / iPadOS
- Android
- macOS
- Windows

## MVP screens
- Auth
- Chats
- Conversation
- Profile

The app is intentionally independent from KD Intelligence. Backend configuration is injected at build time; never commit service secrets.

Next implementation steps: Supabase Auth, profiles, direct chats, Realtime messages, Storage and push notifications.
