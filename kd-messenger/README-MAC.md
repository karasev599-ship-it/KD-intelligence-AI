# KD Messenger — проверка на Mac

KD Messenger работает как обычное веб-приложение и использует Supabase для авторизации, чатов, realtime, профилей и звонков.

## Быстрый запуск

1. Скачай папку `kd-messenger` из ветки `kd-messenger-v1`.
2. Открой Terminal и перейди в эту папку:

```bash
cd ~/Downloads/kd-messenger
```

3. Сделай запускатель исполняемым один раз:

```bash
chmod +x start-mac.command
```

4. Запусти:

```bash
./start-mac.command
```

Откроется браузер на `http://127.0.0.1:8787/`.

## Что проверить

- регистрация и вход;
- создание личного чата через `+`;
- отправка и получение сообщений в двух окнах/браузерах;
- статусы ✓ / ✓✓;
- ответы, реакции, редактирование и удаление;
- профиль, @username, #tag, телефон и QR;
- архив и секретный режим;
- вложения и голосовые сообщения;
- аудио/видеозвонок;
- конфиденциальность;
- список устройств и выход с других устройств;
- чёрный список;
- синхронизация контактов;
- очистка кэша.

Для проверки двух аккаунтов удобно открыть обычное окно Safari и приватное окно Safari либо Safari + Chrome.

## Важно

`http://127.0.0.1:8787` — локальный адрес только для теста на Mac. Для полноценного production-домена потребуется отдельный доступ к Vercel-проекту KD Messenger.

Секретный чат в текущей версии — режим приватности/разделения чата, а не полноценное end-to-end шифрование.
