# KD Messenger — Phase 5 Experience

Phase 5 is the point where KD Messenger stops being a feature checklist and becomes a distinct product.

## KD Spaces

A user can organize conversations, saved messages, files and links into lightweight Spaces. Spaces are private by default and can be shared intentionally.

## Smart Inbox

Messages can be grouped into practical views such as Direct, Groups, Mentions and Unread. The system should never silently hide messages.

## Ask KD

An explicit, user-triggered assistant action for the current conversation. It can summarize a selected range, find action items, or explain a selected message. It never runs passively over private conversations.

## Universal Search

One search field across people, conversations, messages, links, files and media, with filters and fast navigation to the original message.

## Handoff

Open the same conversation on another signed-in device and continue from the same scroll position when possible. Drafts remain device-aware and are not overwritten unexpectedly.

## Privacy Center

A single place for active sessions, notification previews, message deletion controls, blocked users, disappearing-message settings and account export/delete actions.

## Product guardrails

- AI is opt-in and user-triggered.
- Private conversations are not used for ambient profiling.
- No feature may compromise message delivery reliability.
- Every feature has a non-AI fallback where practical.
- Mobile and desktop must share the same product semantics.
