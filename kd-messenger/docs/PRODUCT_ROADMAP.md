# KD Messenger — Product Roadmap

## North star

Build a full messenger that feels immediately familiar, but has a distinct KD identity and useful features beyond a Telegram/WhatsApp clone.

## Phase 1 — Real chat foundation

- Real authentication and sessions
- Profiles and unique @username
- Start a direct chat from a profile
- Conversation list from the database
- Message history
- Realtime delivery
- Read/unread state
- Edit/delete messages
- Reply to messages
- Multi-device sync

## Phase 2 — Media-first messaging

- Photos and videos
- Files and documents
- Voice messages with waveform UI
- Link previews
- Reactions
- Albums
- Message search

## Phase 3 — KD identity

- KD Profile
- Username discovery
- Saved Space
- Custom chat themes
- Per-chat notification controls
- Privacy dashboard
- Active devices/session manager

## Phase 4 — Communication

- Groups
- Roles and permissions
- Invite links
- Audio calls
- Video calls
- Screen sharing on desktop
- Push notifications

## Phase 5 — KD-native features

Features should solve real communication problems rather than add novelty for its own sake. Candidate directions:

- Smart message organization
- Conversation summaries that the user explicitly requests
- Advanced search across messages/media
- Temporary private spaces
- Cross-device handoff
- Smart notification digest
- Rich profile cards

## Product principles

1. Fast before flashy.
2. Familiar interaction patterns, original KD visual language.
3. Privacy and user control by default.
4. No dependency on KD Intelligence.
5. Mobile and desktop are first-class clients.
6. Every new feature must justify its complexity.
